# Clips for the desktop panel

Drop four files in beside this one and the panel on the desktop layout starts
playing them. Nothing else to wire — the names are the wiring.

| File | Plays when |
|---|---|
| `roll-out.mp4` | the sheet is travelling out over the roof |
| `roll-up.mp4`  | the roller is taking it back in |
| `water.mp4`    | the pump is running |
| `idle.mp4`     | nothing is happening — the resting shot |

Until a file exists the panel shows a placeholder naming what is happening, so the
screen still answers "and what does that look like" before a camera has been near a
roof. One missing file does not affect the others.

Keep them short and silent. They are muted and looped, and a roll-out takes about
five seconds on the demo model, so four to eight seconds each is plenty. H.264 in an
`.mp4` plays everywhere; keep each one under a couple of megabytes so the hosted copy
still opens quickly on a phone.
